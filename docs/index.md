## Introduction

This individual datasheet documents the design and
development of the User Controls & Safety subsystem
for Team 107's Simple Educational Robotic Arm.

The purpose of this subsystem is to provide user
controls, monitor emergency-stop requests, and
display operating status.

## Project Summary

Team 107 is developing a low-cost educational robotic
arm capable of performing automated pick-and-place tasks.

The system consists of three subsystems:

1. Arm Motion Control
2. Gripper & Object Handling
3. User Controls & Safety

Each subsystem uses a PIC18F57Q43 Curiosity Nano
microcontroller.

For additional project information, please visit
the [Team 107 Project Report](https://egr304-2026-f-107.github.io/).

## My Contribution

I am responsible for designing the User Controls
& Safety subsystem.

The design includes:

- Emergency Stop Monitoring
- Start/Pause Control
- Speed Control Potentiometer
- Green and Red Status LEDs
- ULN2003A Buzzer Driver
- 5V Power Regulation
- Team Communication Interface

The subsystem schematic was developed using KiCad
and has passed the Electrical Rules Check (ERC).

This datasheet includes the block diagram,
component selection, bill of materials,
schematic design, power budget, and
microcontroller configuration.
